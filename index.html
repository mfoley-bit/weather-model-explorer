ⓘ About these maps

This version does not redraw weather data onto its own map. It displays pre-rendered forecast graphics from the College of DuPage NEXLAB model archive. The site publishes GFS and ECMWF graphics using the same sector and product naming system, which makes side-by-side comparison possible. In Compare mode, this viewer first finds the newest model cycle for which both GFS and ECMWF have Day 8 imagery available, then shows the same forecast hour from that common cycle.

Products shown: Surface Temperature; Total Precipitation Accumulation; 850 mb Wind Speed (roughly 1–1.5 km above sea level); Surface Air Pressure (sea-level pressure contours with precipitation shading); and 500 mb Vorticity/Height (a broad upper-atmosphere pattern map).

Source credit: College of DuPage NEXLAB / Numerical Weather Prediction graphics. COD's terms allow linking to their imagery with credit. Forecasts are educational model guidance, not official warnings.

Graphics: College of DuPage NEXLAB, using GFS and ECMWF numerical model data. This classroom viewer requests only the selected image(s) and does not bulk-download or preload forecast sequences.
